Welcome to lecture two on natural language processing and the Transformer architecture. Historically, sequential text modeling relied on recurrent neural networks, long short-term memory cells, and gated recurrent units. Recurrent architectures process tokens one step at a time from left to right, compressing prior context into a fixed-size hidden state vector. This sequential dependency creates two severe bottlenecks: training cannot be parallelized across sequence positions, and long-range dependencies degrade over hundreds of tokens. Subword tokenization algorithms such as Byte-Pair Encoding and WordPiece first segment raw text into frequent subword units to handle rare words and morphology without out-of-vocabulary errors. Each subword token index is mapped to a dense continuous vector via a learnable embedding lookup table. Because the Transformer removes recurrence entirely, sinusoidal or learned positional encodings are added to token embeddings so the model can distinguish word order. In section two, we analyze scaled dot-product self-attention, the core computational mechanism of the Transformer. For every token in an input sequence, the model projects its embedding into three distinct vectors: a Query vector, a Key vector, and a Value vector. To determine how much attention token A should pay to token B, we compute the dot product between the Query of token A and the Key of token B. These raw compatibility scores are divided by the square root of the key dimension to prevent large dot products from pushing the softmax function into regions with tiny gradients. Applying the softmax operation across all sequence positions yields normalized attention weights that sum to one. Each token then computes a weighted sum of Value vectors, allowing direct contextual information exchange between any pair of words regardless of distance. Multi-head attention runs several self-attention projections in parallel so different heads can attend to syntactic roles, coreference, and semantic relations simultaneously. In section three, we examine the internal block structure of Transformer encoders and decoders. Each Transformer encoder layer wraps the multi-head self-attention module and a position-wise feed-forward network inside residual skip connections and layer normalization. Residual connections allow gradients to flow directly through deep stacks of twelve to ninety-six layers without degradation. In the decoder stack, causal masking sets upper-triangular attention logits to negative infinity so autoregressive generation cannot peek at future tokens. Cross-attention layers in encoder-decoder architectures allow the decoder queries to attend directly over the contextualized representations produced by the encoder. The computational complexity of standard self-attention scales quadratically with sequence length, motivating sliding-window and flash-attention optimizations for long documents. In section four, we compare pretrained Transformer paradigms including BERT, BART, and FLAN-T5. BERT is a bidirectional encoder pretrained using masked language modeling, making it ideal for token classification, named entity recognition, and semantic similarity. BART combines a bidirectional encoder with an autoregressive left-to-right decoder, pretrained as a denoising autoencoder by reconstructing corrupted text spans. This denoising objective makes BART exceptionally effective for abstractive document summarization and text generation. T5, the Text-to-Text Transfer Transformer, reframes every natural language processing task as sequence-to-sequence generation using task-specific text prefixes. Instruction-tuned variants like FLAN-T5 generalize across unseen summarization and question-answering tasks by training on thousands of diverse instruction templates. In section five, we examine subword tokenization algorithms in detail and their impact on vocabulary efficiency and sequence length. Word-level vocabularies struggle with out-of-vocabulary terms, morphological variations, and typographical errors, whereas character-level tokenization produces excessively long sequences that strain quadratic self-attention memory limits. Modern transformers resolve this trade-off using subword tokenization methods including Byte-Pair Encoding, WordPiece, and Unigram SentencePiece. Byte-Pair Encoding iteratively merges the most frequent pairs of adjacent bytes or characters until a target vocabulary size between thirty thousand and fifty thousand subword tokens is reached. Common words remain single tokens, while rare technical terms such as backpropagation or heteroskedasticity are decomposed into meaningful root and suffix subwords, eliminating unknown token errors entirely. In section six, we analyze the computational complexity of self-attention and how hierarchical segmentation handles long contexts. When an encoder processes a sequence of length N with hidden dimension D, computing the pairwise Query-Key attention matrix requires order N squared times D floating-point operations and order N squared memory to store attention weights. Doubling the input sequence length quadruples the memory footprint of the attention map. Standard pretrained models enforce strict positional embedding limits of five hundred and twelve or one thousand and twenty-four tokens. By combining semantic topic segmentation with bounded five-hundred-and-twelve token windows and a sliding sentence overlap, hierarchical summarization pipelines keep memory consumption linear with respect to total lecture duration while preserving cross-boundary semantic continuity. In section seven, we compare extractive summarization baselines against abstractive sequence-to-sequence models in educational applications. Graph-based extractive algorithms such as LexRank and TextRank represent sentences as nodes in a similarity graph, where edge weights reflect cosine similarity between term-frequency vectors, and apply eigenvector centrality to select the most salient verbatim sentences. While extractive summaries guarantee that individual phrases are copied directly from the transcript, they often suffer from dangling pronouns, abrupt topic transitions, and conversational disfluencies inherited from spoken lectures. Abstractive models like BART-Large-CNN and FLAN-T5 rewrite and compress multi-sentence explanations into cohesive, grammatically polished academic prose that reads like human-authored study notes. In our eighth and final section, we review the mathematical formulation of ROUGE and BERTScore for evaluating generated summaries. ROUGE-1 and ROUGE-2 measure unigram and bigram lexical overlap between the candidate summary and reference summary, whereas ROUGE-L computes the longest common subsequence to capture sentence-level word order. Because lexical overlap metrics penalize valid paraphrases that use synonyms, we complement ROUGE with BERTScore, which computes pairwise cosine similarity between contextualized token embeddings of the reference and candidate texts. Evaluating both lexical overlap and semantic embedding alignment provides a rigorous, multi-dimensional assessment of summarization quality across educational lectures.
