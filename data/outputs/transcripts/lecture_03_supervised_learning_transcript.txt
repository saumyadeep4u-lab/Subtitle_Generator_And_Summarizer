Welcome to lecture 3 on supervised machine learning, generalization theory, and rigorous evaluation methodology. In supervised learning, an algorithm observes a training data set of feature vectors paired with ground truth target labels and estimates a mapping function. Expected generalization error on unseen test examples decomposes mathematically into three components, squared bias, variance, and irreducible noise. Bias measures systematic error caused by overly restrictive model assumptions, such as fitting a linear hyperplane to a highly curved decision boundary, resulting in underfitting. Variance measures how sensitively the learned model fluctuates when trained on different random samples drawn from the same underlying population. High capacity models with too many degrees of freedom exhibit low training error but high variance, resulting in severe overfitting. Regularization parameters such as Ridge L2 penalty and Lasso L1 penalty explicitly trade a small increase in bias for a substantial reduction in variance. In section 2, we compare linear classifiers, support vector machines, and tree based ensemble algorithms. Logistic regression models the log odds of binary class membership as a linear combination of input features, optimized by a maximum likelihood estimation. Support vector machines construct a maximum margin separating hyperplane and leverage the kernel trick to project non-linearly separable data into higher dimensional spaces. Decision trees recursively partition the feature space along axis align splits that maximize information gain or minimize geney impurity. While individual deep decision trees suffer from high variance, random forests aggregate predictions across hundreds of bootstrapped trees trained with random feature subsets. Gradient boosted decision trees, implemented in frameworks like XGBoost and LightGBM, build shallow trees sequentially where each new tree fits the negative gradient of the prior ensemble error. Section 3 focuses on data set partitioning, cross validation, and preventing data leakage in applied data science. A common methodological flaw is tuning model hyperparameters or feature selection rules against the final evaluation set, which leaks test information and inflates reported accuracy. Production machine learning workflows enforce a strict three-way split into training, development validation, and unseen held out test partitions. All pre-processing transformers, such as standard scalers, missing value imputers, and vocabulary encoders, must be fit exclusively on the training split and applied unchanged to validation and test data. In K-fold stratified cross validation, the development data is partitioned into K-folds preserving class ratios, rotating the validation fold K times to estimate mean and standard deviation performance. In section 4, we analyze classification metrics beyond simple accuracy for imbalance data sets. When positive fraud or disease cases represent less than 1% of observations, a trivial classifier predicting only the majority class achieves 99% accuracy while failing completely. Precision measures the proportion of positive predictions that are truly positive, controlling false positive alert fatigue. Recall, or sensitivity, measures the proportion of actual positive instances successfully recovered by the model, controlling false negative misses. The F1 score computes the harmonic mean of precision and recall, penalizing extreme imbalances between the two metrics. By sweeping the classification probability threshold from 0 to 1, engineers plot precision recall and receiver operating characteristic curves to select an empirically justified operating point. In section 5, we delve deeper into the mathematical derivation of second order gradient boosting used in modern tabular learning engines. At boosting iteration T, our objective is to find a new regression tree function that minimizes the regularized empirical loss over all training examples, plus a complexity penalty on the number of terminal leaves and the squared L2 norm of leaf weights. By expanding the loss function to the second order using a Taylor series approximation around the current ensemble prediction, the objective simplifies into a sum of linear first order gradient statistics and quadratic second order hash and statistics for every data point. Grouping instances by the terminal leaf they fall into allows us to derive a closed form analytical formula for both the optimal leaf weight and the exact reduction in loss achieved by any candidate feature split. In section 6, we examine subtle data leakage patterns that frequently invalidate supervised learning benchmarks in industry projects. A common mistake occurs when feature scaling, missing value imputation, or target encoding is computed across the entire data set prior to splitting into training and test sets. When global means standard deviations or target statistics incorporate information from test instances, the model gains elicit access to future distribution properties, artificially inflating validation metrics. In time series forecasting and financial modeling, random shuffling across time introduces look ahead bias, engineers must instead use expanding window temporal splits so training data always precedes validation data chronologically. In section 7, we analyze probability calibration and decision threshold optimization for deployment in risk-sensitive applications. While models like logistic regression naturally output well calibrated posterior probabilities, maximum margin classifiers, random forests, and deep neural networks often produce distorted confidence scores that cluster near 0 and 1. Plat scaling fits a monotonic sigmoid transformation on held out validation logits, while isotonic regression fits a non-parametric piecewise constant non-decreasing function to align predicted probabilities with empirical outcome frequencies. Once probabilities are calibrated using briar score and reliability diagrams, analysts select optimal operating thresholds based on asymmetric business cost matrices. In our 8th and final section, we summarize best practices for feature engineering and model interpretability in supervised learning workflows. Domain specific interaction ratios, cyclical trigonometric encodings for time stamps, and out of bold target statistics often yield larger performance gains than switching model families. To explain complex ensemble predictions to stakeholders and regulatory auditors, Shapley additive explanations, or Shap values, compute game theoretic marginal contributions of each feature across all possible feature coalitions. Combining leakage-free cross-validation, calibrated ensemble models, and Shap attribution guarantees transparent and dependable predictive performance.
