Welcome to lecture 2 on natural language processing and the transformer architecture. Historically, sequential text modeling relied on recurrent neural networks, long short-term memory cells, and gated recurrent units. Recurrent architectures process tokens one step at a time from left to right, compressing prior context into a fixed-size hidden state vector. This sequential dependency creates two severe bottlenecks, training cannot be parallelized across sequence positions, and long-range dependencies degrade over hundreds of tokens. Subword tokenization algorithms such as ViPair encoding and WordPace first segment raw text into frequent subword units to handle rare words and morphology without out of vocabulary errors. Each subword token index is mapped to a dense continuous vector via a learnable embedding lookup table. Because the transformer removes recurrence entirely, sinusoidal or learned positional encodings are added to token embedding so the model can distinguish Word order. In section 2, we analyze scale dot product self-attention, the core computational mechanism of the transformer. For every token in an input sequence, the model projects its embedding into three distinct vectors, a query vector, a key vector, and a value vector. To determine how much attention token A should pay to token B, we compute the dot product between the query of token A and the key of token B. These raw compatibility scores are divided by the square root of the key dimension to prevent large dot products from pushing the softmax function into regions with tiny gradients. Applying the softmax operation across all sequence positions yields normalized attention weights that sum to 1. Each token then computes a weighted sum of value vectors, allowing direct contextual information exchange between any pair of words regardless of distance. Multihead attention runs several self-attention projections in parallel so different heads can attend to syntactic roles, coherence, and semantic relations simultaneously. In section 3, we examine the internal block structure of transformer encoders and decoders. Each transformer encoder layer wraps the multihead self-attention module and a position-wise feed-forward network inside residual skip connections and layer normalization. Residual connections allow gradients to flow directly through deep stacks of 12 to 96 layers without degradation. In the decoder stack, causal masking sets upper triangular attention logits to negative infinity so auto-aggressive generation cannot peak at future tokens. Cross-attention layers in encoder decoder architectures allow the decoder queries to attend directly over the contextualized representations produced by the encoder. The computational complexity of standard self-attention scales quadratically with sequence length, motivating sliding window and flash attention optimizations for long documents. In section 4, we compare pret-range transformer paradigms including bird, Bart, and flanty5. Bird is a bi-directional encoder pret-range using mask language modeling, making it ideal for token classification, named entity recognition, and semantic similarity. Bart combines a bi-directional encoder with an auto-aggressive left to right decoder, pret-rained as a denoizing auto encoder by reconstructing corrupted text spans. This denoizing objective makes Bart exceptionally effective for abstractive document summarization and text generation. T5, the text to text transfer transformer, reframes every natural language processing task as sequence to sequence generation using task-specific text prefixes. Instruction-toon variants like flanty5 generalize across unseen summarization and question answering tasks by training on thousands of diverse instruction templates. In section 5, we examine subword tokenization algorithms in detail and their impact on vocabulary efficiency and sequence length. Word-level vocabulary struggle without a vocabulary terms, morphological variations, and typographical errors, whereas character-level tokenization produces excessively long sequences that strain quadratic self-attention memory limits. Modern transformers resolve this trade off using subword tokenization methods including bipair encoding, word-piece, and unigram sentence-piece. Bipair encoding iteratively merges the most frequent pairs of adjacent bytes or characters until a target vocabulary size between 30,000 and 50,000 subword tokens is reached. Common words remain single tokens, while rare technical terms such as back propagation or heteroscodasticity are decomposed into meaningful root and suffix subwords, eliminating unknown token errors entirely. In section 6, we analyze the computational complexity of self-attention and how hierarchical segmentation handles long contexts. When an encoder processes a sequence of length and with hidden dimension D, computing the pairwise query key attention matrix requires order n squared times D floating point operations and order n squared memory to store attention weights. Doubling the input sequence length quadruples the memory footprint of the attention map. Standard pretrained models enforce strict positional embedding limits of 512 or 1024 tokens. By combining semantic topics segmentation with bounded 512 token windows and a sliding sentence overlap, hierarchical summarization pipelines keep memory consumption linear with respect to total lecture duration while preserving cross-boundary semantic continuity. In section 7, we compare extractive summarization baselines against abstractive sequence to sequence models in educational applications. Graph-based extractive algorithms such as LexRank and TextRank represent sentences as nodes in a similarity graph, where edge weights reflect cosine similarity between term frequency vectors, and apply eigenvectors centrality to select the most salient verbatim sentences. While extractive summaries guarantee that individual phrases are copied directly from the transcript, they often suffer from dangling pronouns, abrupt topic transitions, and conversational disfluencies inherited from spoken lectures. Abstractive models like Bartlarge CNN and Flan T5 rewrite and compress multi-sentence explanations into cohesive, grammatically polished academic prose that reads like human authored study notes. In our eighth and final section, we review the mathematical formulation of Rouge and Bird score for evaluating generated summaries. Rouge 1 and Rouge 2 measure unigram and program lexical overlap between the candidate summary and reference summary, whereas Rouge L computes the longest common sub sequence to capture sentence-level word order. Because lexical overlap metrics penalize valid paraphrases that use synonyms, we complement Rouge with Bird score, which computes pairwise cosine similarity between contextualized token embeddings of the reference and candidate texts. Evaluating both lexical overlap and semantic embedding alignment provides a rigorous, multi-dimensional assessment of summarization quality across educational lectures.
